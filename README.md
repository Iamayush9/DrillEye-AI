# DrillEye-AI  
## AI Powered NCC Drill Analysis System  

DrillEye is a computer-vision based AI system designed to analyze NCC cadet drill performance in real time.  
It detects posture accuracy, movement precision, and parade discipline using pose estimation and structured drill rules.

---

##  Features

-  Real-time cadet posture detection  
-  Drill movement accuracy analysis  
-  Body alignment & stance evaluation  
-  Performance feedback system  
-  AI workflow based drill correction engine  
-  Web interface built with Next.js  
-  Firebase deployment ready
